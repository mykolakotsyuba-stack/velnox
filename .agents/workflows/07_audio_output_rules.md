# macOS Audio Output Rules

## Контекст
Користувач працює з Jarvis у двох режимах:
- **Запис наради** — system audio з Teams через BlackHole 2ch у Jarvis
- **Прослуховування** — потрібен фізичний вихід (динаміки/навушники)

Якщо забути переключити з BlackHole після наради → звук не чути (BlackHole = virtual loopback).

## Команди
```bash
SwitchAudioSource -c -t output                           # який зараз?
SwitchAudioSource -a -t output                           # доступні
SwitchAudioSource -t output -s "Динаміки MacBook Pro"    # переключити
```

## Назви пристроїв (українська локалізація)
- `BlackHole 2ch` — loopback для запису, **НЕ для прослуховування**
- `Зовнішні навушники` — підключені дротові навушники (можуть бути не під'єднані)
- `Динаміки MacBook Pro` — вбудовані динаміки, завжди працюють
- `Microsoft Teams Audio` — віртуальний девайс Teams
- `Пристрій із багатьма виходами` — multi-output aggregate

## Правила реакції

**"Не чую"** → спершу перевір `SwitchAudioSource -c -t output`. Якщо BlackHole → одразу переключи на `Динаміки MacBook Pro`. НЕ пропонувати "перевір гучність" як перше — користувач знає.

**"Переключи на навушники"** → `Зовнішні навушники`. Якщо не чути — швидко на `Динаміки MacBook Pro` (навушники можуть бути фізично не під'єднані).

**"Переключи на динаміки"** → `Динаміки MacBook Pro`.

**Після наради коли користувач завершив запис** — нагадати/запропонувати переключити з BlackHole на динаміки.
