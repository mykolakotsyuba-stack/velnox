# Вихідні матеріали

Тут лежать джерела, з яких зібрано каталог: CSV і XLSX із таблицями від
власника, PNG-схеми та креслення, PDF-каталоги, GLB-моделі. Раніше все це
лежало розсипом у корені репозиторію (109 записів), тепер — тут.

- `materials/` — під git. Ці файли читає `KitTableSeeder.php`
  (`base_path('../materials/...')`), з них збиралися таблиці kit.
- `materials/inbox/` — **поза git**. Приймальня для щойно отриманих матеріалів:
  фотопартії, макети, PDF від дизайнера. Розібрав — переклав у `materials/`
  або туди, де файл справді потрібен (наприклад `velnox-frontend/public/images/`).

⛔ Зображення для сайту сюди не кладуть. Їхнє місце —
`velnox-frontend/public/images/products/{table-slug}/`, інакше дев їх не віддасть.
